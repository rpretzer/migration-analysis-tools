## What it is

An **AI-native product development pipeline** that takes a product manager's business intent and produces analyzed, specified, coded, tested, and quality-gated deliverables — with full observability at every step. The system extends a proven analysis methodology into a complete development workflow where all code is generated by structured AI agents, all testing is automated, and every decision is traceable.

## What it does next (pipeline)

The pipeline extends analysis into execution with seven AI agents:

```
PM/PO → Coach → Spec Compiler → Coding Agent → Test Agent → Quality Gate → Human Review → Merge
```

| Agent | What it does | Human involvement |
|-------|-------------|-------------------|
| **Coach** | Guides PM through structured inquiry. Pushes back on vague inputs. Produces business cases and stories. | PM confirms stories match intent |
| **Spec Compiler** | Transforms stories into machine-consumable specs grounded in actual codebase | None (auto-validated) |
| **Coding Agent** | Generates code from specs. Stops on ambiguity instead of guessing. | None |
| **Test Agent** | Independent validation. Tests both flag-on and flag-off states. | None |
| **Quality Gate** | Structured checks. Tells reviewer exactly what to inspect. | Tech lead reviews flagged items only |
| **Codebase Analyst** | Maintains durable model of codebase state across all platforms | None |
| **Observability** | Audit trail. Backward tracing when output is wrong. | On-demand |

**Every decision is logged and traceable.** When output is wrong, trace backward from the failing check through the spec to the original PM input.

## Target architecture: CLEAN + KMP + CMP + BFF

The architecture analysis revealed that Hoopla's 7+ client platforms duplicate business logic. The recommended target:

- **BFF layer** (new): Three Backend-for-Frontend services (Mobile, Web, TV) aggregate backend calls into single screen-level responses. Business logic executes server-side. A rule change deploys to the BFF once, not to 7 clients.
- **KMP** (Kotlin Multiplatform): Shared client module for networking and offline sync. Scope reduced from ~60% to ~30% of client code because BFF handles business logic.
- **CMP** (Compose Multiplatform): Shared UI across Android, iOS, and web.
- **Native** (sparing): DRM playback, push notifications, biometrics only.

## Why Claude Code is required

| Capability | Why it matters | Alternatives lack it |
|-----------|---------------|---------------------|
| **Model selection per task** | Opus for judgment ($), Sonnet for bulk work ($$), Haiku for transforms ($$$). Full analysis: ~$65. | Single-model tools cost 3-5x more or sacrifice quality. |
| **Multi-agent orchestration** | Separate context windows per agent. Codebase analyst reads 1,200+ classes without consuming other agents' context. | GitHub Copilot: one issue, one repo, no inter-agent communication. |
| **Persistent methodology** | 28-section operating manual (CLAUDE.md) + 27-file methodology layer. Not ad-hoc prompting. | Competing tools have instruction limits (30k chars for Copilot). |
| **MCP integration** | 7 MCP servers expose structured context: codebase state, observability, pipeline status, validation, external integrations. | No equivalent in competing tools. |
| **Full observability** | Every agent decision logged. Backward tracing from any output to PM intent. | No competing tool provides this natively. |
